# v0.2.1 资源校验记录

17 个资源包严格检查均无结构错误。全集 ZIP 另经生产 Rust 导入器验证，可导入 17 个唯一 ID。

## 保留的原素材差异

- 派蒙、皮克啾只有待机动作；其他部分角色缺少独立睡眠或强提醒动作，目录 JSON 逐项列出。
- 若干像素待机/睡眠动作变化很小，按原素材保留，没有伪造运动。
- 椿、纳西妲部分动作超过 512 像素，保留原分辨率，应用按桌宠尺寸缩放。
- 像素猫扩充版的 `kongzi` 动作为不透明特殊画面，保留原貌；不放入随机待机池。
- 四个旧包的随机待机池已收敛到安静动作；所有源动作、图像和音频仍可手动选择。
- 资源说明中的维护者本机绝对路径已移除，原始本地目录未改写。
