# Focus Pet 0.2.1 — 手绘涂鸦主题

按用户提供的 Hand-drawn / Doodle 规范替换构成主义主题，保留其余两个主题。旧的 `constructivism` / `terminal-hacker` 选择自动映射到 `hand-drawn`。

## 实现

- 暖纸底色、静态纸张纹理、略有波动的墨线、马克笔色块、页边涂鸦。
- 中文标题采用离线手写字体子集，约 129 KB；正文和统计数字保持系统字体与稳定排版。
- 字体来源与再生成方式见 `src/assets/fonts/README.md`；许可证随构建发布到 `licenses/Focus-Pet-Hand-OFL.txt`。
- 仅装饰性标题轻微倾斜，交互命中区域和数据布局保持稳定；支持减少动态效果偏好。
- 正文、次要文本、选中控件和常用语义文字的颜色对比度校验值为 6.1:1 至 12.9:1。
- 桌宠窗口继续透明，纸张背景只用于主界面。
- 同时修复主题预览在窄屏下高度塌陷的旧问题，并校正窄窗口导航及时间窗标题换行。

## 验证

- 54 项单元测试通过，包含旧主题迁移。
- 18 项桌面/移动视口回归通过，包含主题选择、持久化、中文字体加载、缩略图尺寸与原有交互。
- TypeScript/Vite 构建、lint、CSS token 检查通过。
- 正式 macOS 应用中已确认：只显示新粗野主义、中世纪现代、手绘涂鸦三个选项，当前选中手绘涂鸦，输入监听仍可用。
- 默认 Tauri DMG 脚本失败；签名应用构建成功后，使用系统 `hdiutil` 制作包含应用和 Applications 快捷入口的 UDZO 安装包，完整性校验通过。
- `/Applications/Focus Pet.app` 已更新为 0.2.1，并从正式安装位置启动。
- 安装包：`release/Focus-Pet-0.2.1-macos-arm64-20260926.dmg`。
- 日志：`output/doodle-validation-20260926/`；截图：`output/playwright/doodle-*.png`。

## 历史文件功能现状

本轮未修改历史保留策略。目前是自动无损合并：启动时合并相邻且元数据相同的片段，运行时合并连续记录，并以紧凑 JSON 批量保存。它保留历史时间段和统计信息；没有按重要性自动删除、按年龄淘汰旧明细或仅保留日/月摘要的策略。
