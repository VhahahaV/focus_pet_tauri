# Focus Pet v0.2.1 — 轻量专注与完整桌宠资源库

应用与桌宠分开提供。请在下方 Assets 下载适合系统的安装包，再选择桌宠全集、分类合集或单包导入。

## 应用

| 系统 | 文件 |
| --- | --- |
| macOS Apple Silicon | `Focus-Pet-0.2.1-macos-arm64.dmg` |
| macOS Intel | `Focus-Pet-0.2.1-macos-x64.dmg` |
| Windows x64 | `Focus-Pet-0.2.1-windows-x64-setup.exe` |
| Linux x64 | `Focus-Pet-0.2.1-linux-x64.AppImage` / `.deb` |

macOS 构建采用 ad-hoc 签名、未公证；Windows 构建没有商业代码签名。每个应用安装包附带 SHA-256 文件。macOS 已做本机运行验证；其他架构通过对应平台 CI 构建与测试，仍欢迎反馈实机兼容性问题。

## 桌宠资源

**全部 17 个桌宠已归档，资源归档版本与应用保持 0.2.1。**

- **全集**：`FocusPet-Pets-All-0.2.1.zip`，一次导入 17 个桌宠。
- **应用图标演示（1）**：`FocusPet-Pets-demo-0.2.1.zip`。
- **像素与猫系（5）**：`FocusPet-Pets-pixel-0.2.1.zip`。
- **角色与萌宠（3）**：`FocusPet-Pets-companions-0.2.1.zip`。
- **游戏角色（8）**：`FocusPet-Pets-game-characters-0.2.1.zip`。
- **单包**：`FocusPet-Pet-<id>-0.2.1.zip`，可单独下载，不必下载全集。
- **索引与校验**：`FocusPet-Pets-Catalog-0.2.1.json`、资源 README 和 `SHA256SUMS.txt`。

[查看预览、原作者及每只桌宠的下载链接](https://github.com/VhahahaV/focus_pet_tauri/blob/v0.2.1/docs/pet-packs/README.md)

导入方法：应用 → 桌宠 → 导入 → ZIP 文件。全集、分类合集及单包均可直接导入，不需要先解压。派蒙、皮克啾仅包含待机动作；其他资源保持原始动作范围和音频。

图片、动画和音频保留原作者与原始授权标记。第三方或授权未明确的素材仍标记 `localOnly` / `unknown`，不自动取得软件仓库的许可；仅用于个人本地体验，二次分发或商用需要确认原作者许可。

## 应用改进

- 删除智能体会话卡片、后台会话读取、Hook、App Server、SSH 发现与连接逻辑。
- 修复 macOS 双击少计、修饰键松开多计、诊断刷新造成输入漏计，以及空闲回退虚增次数。
- 工作应用中的安静阅读/思考不再仅因短暂无输入判为走神；修复重启后的连续状态计时。
- 合并重复历史片段，优化历史合并与批量保存；现有历史信息保留，不自动淘汰旧明细。
- 用手绘涂鸦替换构成主义，提供离线中文手写标题字体、纸张纹理和可访问的控件状态。

不包含用户个人活动记录、设置、令牌、缓存或日志。资源索引记录各包动作数、帧数、大小和 SHA-256；安装包与资源版本一致。
